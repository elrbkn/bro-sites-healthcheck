# Site Health Check → Telegram

Открывает список сайтов **через прокси** в headless-браузере,
проверяет, что сайт реально загрузился (не 4xx/5xx, есть контент, есть
интерактивные элементы), и присылает понятный отчёт в Telegram-чат.

## Что именно проверяется (health check)

Для каждого сайта:
1. Страница открывается через реальный браузер (Chromium) под прокси — не просто `fetch`, а полноценная загрузка с JS, как у пользователя.
2. Проверяется HTTP-статус основного запроса — фейл, если `>= 400` (4xx/5xx).
3. Проверяется, что на странице действительно есть контент (текст длиннее `MIN_CONTENT_LENGTH` символов) — фейл, если страница пустая/белая.
4. Проверяется текст страницы на маркеры типовых "заглушек" (404/502/access denied/domain for sale/cloudflare-блок и т.п.) — фейл, даже если формально отдался HTTP 200.
5. Проверяется наличие интерактивных элементов (ссылки, кнопки, поля ввода) — если их нет, сайт всё равно считается "успешным", но в отчёте будет ⚠️ предупреждение, что взаимодействие может быть недоступно.
6. При сетевой ошибке/таймауте делается повторная попытка (`RETRY_COUNT`, по умолчанию 1).

По каждому сайту в отчёт попадают: статус (✅/❌), HTTP-код, время загрузки, причина ошибки (если есть) и предупреждения.

## Установка

```bash
npm install
npx playwright install --with-deps chromium   # если postinstall не сработал сам
```

## Настройка

Все параметры — в файле `.env`:

```dotenv
# SOAX прокси
SOAX_HOST=proxy.soax.com
SOAX_PORT=5000
SOAX_LOGIN_PREFIX=package-xxxxx-country
SOAX_LOGIN_SUFFIX=opt-lookalike
SOAX_PASSWORD=...
PROXY_COUNTRY=de              # страна, под которой открываем сайты
PROXY_ROTATE_SESSION=true     # true = каждый запуск/попытка получает новый IP из пула DE

# Telegram
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...
TELEGRAM_PROXY_URL=http://127.0.0.1:10809   # прокси для доступа к api.telegram.org (можно оставить пустым, если Telegram доступен напрямую)

# Health check
PAGE_TIMEOUT_MS=30000
RETRY_COUNT=1
CONCURRENCY=3           # сколько сайтов проверяем одновременно
MIN_CONTENT_LENGTH=50
```

Логин прокси формируется автоматически по шаблону SOAX:
`SOAX_LOGIN_PREFIX-PROXY_COUNTRY[-sessionid-XXXX]-SOAX_LOGIN_SUFFIX`,

## Список сайтов

Редактируется в файле `sites.js` (имя + URL).
Если у сайта не указан протокол (например `cabinet.chocopay.io`), автоматически используется `https://`.

## Запуск

```bash
npm start
```

В консоли будет прогресс по каждому сайту, а в конце — отчёт (тот же, что уйдёт в Telegram).

Код возврата процесса:
- `0` — все сайты ок,
- `1` — есть хотя бы один сайт с ошибкой,
- `2` — не получилось отправить отчёт в Telegram.

Для автоматизации (cron, CI, systemd) — по коду возврата можно триггерить дополнительный алерт.

## Регулярный запуск (cron, каждый час)

```bash
0 * * * * cd /path/to/site-healthcheck && /usr/bin/node src/index.js >> healthcheck.log 2>&1
```

## Структура проекта

```
site-healthcheck/
├── .env                # реальные настройки
├── .env.example         # шаблон настроек
├── sites.js              # список проверяемых сайтов
├── package.json
└── src/
    ├── config.js         # загрузка и валидация конфигурации
    ├── proxy.js           # формирование логина/пароля SOAX прокси
    ├── checker.js          # логика health check одного сайта (Playwright)
    ├── report.js            # форматирование отчёта
    ├── telegram.js            # отправка отчёта в Telegram (через локальный прокси)
    └── index.js                # точка входа: параллельный запуск проверок + отчёт
```
